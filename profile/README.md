# Machine Squared

[Machine on a Mission](https://machineonamission.me/) experiments in ["vibe coding"](https://en.wikipedia.org/wiki/Vibe_coding), i.e. code entirely written by generative AI like large language models.

This GitHub organization exists to entirely separate LLM-generated code from [my handwritten code](https://github.com/machineonamission/)

I am working on setting up a fully local model, hyper tailored/optimized to my hardware, that i can run via a harness like opencode to compensate for non frontier performance with a harness loop.

I dislike "vibe coding" where I am entirely unaware of the code. My ideal setup is an LLM smart enough to "work under me", I work hard to help it generate good code (giving lots of guidelines and prompts) and then i review every line of code it generates and every reason and purpose of everything. I still understand every line of code in my repository, but I am curious what if a machine wrote it, now that LLMs are capable coding agents.
